❓ COMMON QUESTIONS

Q: How much does this cost?
A: FREE! Vercel free tier includes:
   • 1000 deployments/month
   • Unlimited bandwidth
   • Global CDN
   • SSL/HTTPS

Q: How long does deployment take?
A: ~5 minutes total:
   • Python install: 1 min
   • API fetch: 2-3 minutes
   • Vercel deploy: 1 minute

Q: What if the API fetch fails?
A: The site still works with mock data.
   expert_data.json has fallback data included.

Q: Can I add more experts?
A: YES! Edit gatekeeper_backend_enhanced.py
   Add expert names → Run script → Redeploy

Q: Can I use a custom domain?
A: YES! Configure in Vercel dashboard

Q: What about data privacy?
A: Only public records used. No personal data.
   GDPR compliant.

Q: Can I embed this on my website?
A: Not directly, but you can iframe it
   Or modify HTML for embedding

Q: What if I need a different industry?
A: Add to backend script, rerun, redeploy
   Supports unlimited industries
