## 🚀 QUICK DEPLOY GUIDE (5 MIN)

### **Files You Need**

Download from `/mnt/user-data/outputs/`:

1. `gatekeeper_multi_industry.html` (18 KB) — Website
2. `expert_data.json` (31 KB) — Database
3. `gatekeeper_backend_enhanced.py` (22 KB) — API fetcher
4. `deploy.sh` or `deploy.bat` (automation)

### **Step 1: Install Dependencies**

**Mac/Linux:**
```bash
pip3 install requests
```

**Windows:**
```bash
python -m pip install requests
```

### **Step 2: Fetch Real Data**

```bash
python3 gatekeeper_backend_enhanced.py
```

Wait 2-3 minutes. This fetches live data from:
- RetractionWatch, ORCID, NIH, CrossRef, PubMed, arXiv, USPTO

### **Step 3: Deploy to Vercel**

**Option A: Automated Script (Recommended)**

Mac/Linux:
```bash
chmod +x deploy.sh
./deploy.sh
```

Windows:
```bash
deploy.bat
```

**Option B: Manual Deploy**

```bash
npm install -g vercel
vercel --prod
```

Follow the prompts. You'll get:

```
🎉 Production Deployment Ready!
URL: https://gatekeeper-XXXXX.vercel.app
```

### **Step 4: Test & Share**

- Visit your live URL
- Test search & filters
- Share with team! 🎉

**Time:** ~5 minutes total

## 📞 SUPPORT & RESOURCES

### **Quick Deploy Issues**

1. **Python not found**
   - Install from https://www.python.org/downloads/
   - Make sure to check "Add to PATH"

2. **Vercel deploy failed**
   - `npm install -g vercel`
   - Make sure you're logged in

3. **API fetch timed out**
   - Check internet connection
   - Run again: `python3 gatekeeper_backend_enhanced.py`
   - Mock data will work if APIs fail

### **Higgsfield Issues**

1. **MCP won't connect**
   - Make sure you're in Claude Code (desktop app)
   - Run: `claude mcp list`
   - Check Higgsfield account is created

2. **Motion Website Generator not found**
   - Reload Claude Code
   - Verify MCP connection
   - Check Higgsfield credits available

3. **Website looks wrong**
   - "Make this fully responsive on mobile"
   - "Adjust the color palette"
   - "Slow down animations"
