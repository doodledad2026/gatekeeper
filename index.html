Get Started

Deploy your own instance

Free, static, and live in under five minutes.

⚡ Automated

One command fetches live data and deploys to Vercel.

chmod +x deploy.sh ./deploy.sh

🛠️ Manual

Fetch data yourself, then deploy with the Vercel CLI.

python3 gatekeeper_backend_enhanced.py vercel --prod

🔁 GitHub → Vercel

Push to GitHub and connect the repo for auto-deploys on every commit.

git push origin main # then import the repo on vercel.com/new
